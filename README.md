# VelocisType — Precision Touch Typing Speed 

VelocisType is a modern, high-performance web application engineered for touch typing practice, velocity benchmarking, real-time error diagnostics, and skill certification. Built with React 18, TypeScript, and Tailwind CSS, it offers a distraction-free typing environment paired with rich analytics.

---

## 🌟 Key Features

### ⚡ Practice & Benchmarking Modes
- **Time Sprint**: 15s, 30s, 60s, and 120s test durations.
- **Word Sprint**: Fixed target lengths (10, 25, 50, or 100 words).
- **Quote Mode**: Inspirational, literary, and historical passages categorized by length.
- **Custom Passage & Drills**: Paste custom text or target weak keys identified by AI error heatmaps.

### 🙈 Zen Mode & Blindfold Typing
- **Zen Mode**: Hides top navigation, footer, and stats while actively typing to maximize focus.
- **Blind Test Mode**: Disables real-time letter coloring to test pure tactile muscle memory.

### 🎯 Interactive Virtual Keyboard & Finger Guide
- Live key highlighting that animates required key presses in real-time.
- Finger-to-key color mapping to reinforce proper touch-typing ergonomics.

### 🔊 Mechanical Key Sound Synthesizer
- Built-in Web Audio API synthesizer simulating realistic tactile switch sound profiles (Cherry MX Blue, Brown, Red, Topre, and Minimalist Click).

### 📊 Pro Analytics & Error Heatmaps
- **WPM & Accuracy Trends**: Interactive charts showing speed progression over time.
- **Key Error Matrix**: Identifies specific key combinations causing the highest error rates.
- **Finger Weakness Breakdown**: Quantifies accuracy across all 10 fingers.
- **AI Performance Insights**: Contextual feedback on consistency, error spikes, and velocity ceilings.

### 🏆 Gamified Challenges & Badges
- 15+ curated challenges spanning **Easy**, **Medium**, **Hard**, and **Legendary (100+ WPM)** tiers.
- Earn XP rewards, unlock achievements, and collect shareable badges.

### 📜 Verified Typing Certificates & Social Share Cards
- Downloadable PNG certificates of achievement for milestone speeds (50, 75, 100+ WPM).
- **Canvas-based Share Cards**: High-resolution image generation for sharing milestones on X/Twitter and social media.

### 📚 SEO-Optimized Guide, Blog & Knowledge Hub
- In-depth articles covering touch typing fundamentals, posture, speed training routines, and equipment selection.
- Search engine optimized content structure meeting Google AdSense compliance guidelines.

---

## 🛠️ Tech Stack

- **Frontend**: React 18 (TypeScript)
- **Styling**: Tailwind CSS, Lucide React Icons
- **Audio Engine**: Web Audio API Sound Synthesizer
- **Visuals & Effects**: Canvas API, `canvas-confetti`
- **Build Tooling**: Vite, ESBuild

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/velocistype.git
   cd velocistype
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Launch local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
