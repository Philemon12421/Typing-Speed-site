> **VelocisType** is a modern, high-performance web app for touch typing practice, velocity benchmarking, real-time error diagnostics, and skill certification — built with React 18, TypeScript, and Tailwind CSS. Distraction-free typing, paired with analytics that actually tell you what to fix.

## 🚀 Getting Started

### Prerequisites
- Node.js `v18+`
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/velocistype.git
cd velocistype

# 2. Install dependencies
npm install

# 3. Launch the local dev server
npm run dev

# 4. Build for production
npm run build
```

Once running locally, open `http://localhost:5173` — or just skip all of that and try the [**hosted version**](https://typerca.vercel.app) instead. 🚀
